# Changelog

## 0.1.0-alpha - 2026-04-19

Initial public alpha preparation.

- Zero-config local scanning with saved runtime state.
- Broad-root scanning with cache/vendor/generated noise suppression.
- Monorepo root/subproject/container relationship labels.
- Duplicate clustering with explainable signals.
- Recommendation labels for inspect, keep, archive, merge, duplicate, and reconciliation cases.
- AI handoff and brief artifacts.
- Repomix-backed digest and full-pack generation.
- Optional GitHub reconciliation through `gh`.

This release is intended for early testing. CLI details, output schemas, and scoring
heuristics may change.
